# HEP 分析流水线

按实际流程组织 `raw → reco → selection → analysis → 物理结论`。默认 `flowchart TB`，上下游从上到下，同一步骤的多路输入并排，箭头表示 `输入 → 脚本 → 产物`。横版图可用 `LR`，同级输入上下并列。

| 角色 | 形状和颜色 | 标签 |
|---|---|---|
| 脚本 | 浅蓝矩形 | 文件名或入口 + 功能 |
| Data I/O | 浅绿圆柱 | `Data` + 内容和阶段 + 格式 |
| MC I/O | 浅橙圆柱 | `MC` + 真值、重建级或选后内容 + 格式 |
| 外部输入 | 浅紫六边形 | 校准、外部参数等 + 来源或格式 |
| 结果 | 浅红胶囊 | 物理量或结论 + 输出载体 |

- 数据格式写实际载体，例如 ROOT `TTree`、ROOT `TH1`、内存 NumPy 数组或 `.npy` 文件。脚本按样本分别运行时注明，保留 Data 和 MC 的各自路径，直到实际比较、修正或联合推断。
- 将外部输入放在消费步骤附近。先用真实的读写关系排列；需要微调时用 `~~~` 不可见定位边，并在源码注明它只用于对齐。以成图核对分支、汇合和先后关系。
