# academic-writing-studio · 学术写作工作室

协助整理文献、研究结果和草稿，并记录主张与依据的对应关系。你可以用它比较论文、规划综述、起草稿件、编辑与翻译段落，或检查审稿回复。技能按文章类型和本轮目标选择工作方法，包含高能物理（HEP）写作指引。

## 特点

- **区分文章类型。** 完整研究Article、原创研究Letter、Review、Perspective和学术评论分别处理。期刊Letter、致编辑信与投稿附信也会区分。
- **确认成稿语言。** 未确定语言时，按文体给出默认选项并询问一次；已明确的选择继续沿用。中文粒子物理稿件可查附件词典整理的中英词目与原书页码。
- **先用已有材料。** 先梳理已提供的文献、笔记和结果，再围绕缺口补充检索，记录范围与停止依据。
- **追踪主张的依据。** 分别记录文献身份、实际读取范围、原文位置及其对主张的支持程度。原文无法访问时保留相应状态。
- **把调研接到论证。** 从文献比较中明确问题、贡献、证据和推断条件，区分已有支持的结论与待补的分析。
- **按任务控制深度。** 局部润色可直接处理；完整起草或大修时，按需要使用论证骨架、证据表和续接记录。工作由当前助手完成。
- **减少模板化表达。** 起草与修改时顺手检查空泛强调、套式开头、机械衔接等常见模式，保持术语和证据强度，直接交付本轮所需文本。
- **支持HEP语境。** 检查测量量、相空间、数据与版本、模型假设、系统误差及统计含义，也关注共享样本和组合结果的依赖。

## 适合哪些文体

| 文体或交付物 | 主要处理内容 |
|---|---|
| Research Article | 实验、理论、计算与模拟研究的完整论证 |
| Research Letter | 核心原创贡献、短格式证据安排及具体栏目要求 |
| Review | 叙述、批判、技术、进展、系统与范围综述，以及元分析等 |
| Perspective / Opinion / Roadmap | 立场、支持与反对证据、方向和里程碑 |
| Correspondence / Comment / Reply | 致编辑信、发表后评论与回复；按刊物定义处理 |
| 方法、软件、数据与方案类论文 | 贡献类型、验证要求和报告信息 |
| 会议沟通 | 摘要、proceedings论文、口头报告、海报及参会总结 |
| 其他研究文本 | 学位论文、书章、技术报告、研究计划、投稿信和审稿回复 |

## 如何开始

在已安装本技能的对话环境中，写出技能名和你这次要完成的任务：

```text
使用 $academic-writing-studio，检查这段英文引言的逻辑和表达。
保留科学含义、数字和引用，给出修改稿及必要说明。
```

没有指定成稿语言时，助手会先确认，并给出[文体默认语言](SKILL.md#先确定文章类型)。回复“按默认”即可采用该选项，也可指定其他语言或不同交付物分别用语。该表记录你的写作偏好；投稿时另需满足目标刊会要求。

例如：“为这组HEP论文写一篇Review，按默认语言，遇到专业术语查词典。”会采用中文；“写一篇英文Review”则直接采用英文。

任务涉及较多材料时，可补充以下信息：

1. **目标：** 比较文献、形成提纲、起草、修改、翻译，或核验回复。
2. **材料：** 论文全文、阅读笔记、图表、结果说明、草稿或审稿意见。
3. **文体与读者：** 目标期刊、会议、文章类型、读者背景及成稿语言。
4. **处理范围：** 指定段落或全文、篇幅要求、允许补检的范围及需要保留的内容。

不必为局部任务填写整套简报。直接贴出文本并说明要求即可。文章类型尚未确定时，可以先让技能根据材料评估适合的文体。

## 使用案例

以下提示词可复制后按实际任务修改；所提到的文件、文献和结果需要在使用时提供。

### 比较一组论文

```text
使用 $academic-writing-studio，比较这些论文的WHY、HOW、WHAT：
分别解决什么问题、采用什么方法、得到什么结果，还有什么未解决。
先基于我提供的材料，标明版本和实际读取范围，最后给出跨篇比较表与缺口。
```

交付重点：逐篇比较、共同问题、方法差异、可比条件和后续阅读方向。

### 规划HEP技术综述

```text
使用 $academic-writing-studio，为喷注标记方法写一份技术综述提纲。
先盘点现有文献，按训练样本、验证域、工作点和不确定度建立比较维度。
说明算法指标与物理灵敏度之间还需要哪些证据，列出需补检的主题。
本轮只交付提纲与证据缺口。
```

交付重点：综述范围、主题结构、比较维度及证据缺口。需要系统综述时，另行明确协议与实际检索、筛选和评价工作。

### 评估Article转为研究Letter

```text
使用 $academic-writing-studio，评估这份完整研究稿是否适合改写为PRL Letter。
根据现有结果识别可以独立成立的核心贡献，建议主文与补充材料的安排。
核对目标栏目现行指南，列出压缩后会影响论证完整性的地方。
```

交付重点：文体适配评估、核心证据安排及修改建议。转换过程中要检查是否仍有足够证据支撑研究结论。

### 起草结果小节

```text
使用 $academic-writing-studio，根据这些图、方法说明和已核对的数值，
为PRD研究Article起草一个Results小节。
先确定每组图回答的问题，再组织结果与必要解释；缺少的信息具体标出。
```

交付重点：围绕研究问题组织的结果文本、图文对应关系和待补信息。

### 局部翻译与润色

```text
使用 $academic-writing-studio，把下面的讨论段落改写成清楚的学术英文。
保留数值、公式、引用、条件和证据强度，只处理这段文字。
若某处原意有歧义，请单列说明。
```

交付重点：指定范围内的修改稿，以及需要作者判断的含义问题。

### 检查审稿回复

```text
使用 $academic-writing-studio，核对审稿意见、原稿、修订稿和这份回复信。
把每条意见中的要求与回复承诺拆开，检查实际改动是否完成。
给出对应位置、完成情况及剩余动作，并检查修订是否引入了新的不一致。
```

交付重点：关切、承诺、实际改动和复核结果的对应表。

### 准备会议报告

```text
使用 $academic-writing-studio，把这些研究结果组织成15分钟的口头报告。
听众是相邻HEP方向的研究者。给出核心问题、图组顺序、时间预算和问答准备。
尚未演练的时间标为估算，并保留结论的适用条件。
```

交付重点：报告结构、图组证据路径、时间估算和可能的科学质疑。会议论文、海报和参会总结也可单独指定。

## 可以期待怎样的输出

输出随本轮目标变化：可以是一段修改稿、一份比较表、一套提纲或逐点回复。助手从已有材料整理需要的模板，并将待核实信息标明。长任务可保存当前稿件、证据位置、版本依赖和下一步，以便继续。

这些流程用于组织与检查写作。结论的可靠性取决于实际研究和可获得的证据。核验结果会列出已查范围和未完成项。提交前需要核查目标刊会的现行要求，并由作者判断科学解释和最终稿件。
