# 写作决策速查

| 看到的情况 | 当前行动 | 理由/下一步 |
|---|---|---|
| 只说“期刊文章” | 根据科学目的识别Article、Review、观点或评论 | 出版载体不能替代文章类型 |
| PRL/PRD等研究型Letter | 读ch12，选择自洽的核心贡献与证据 | Letter栏目规则及受众按具体刊物 |
| “Letter”用途不明 | 根据上下文区分研究短文、致编辑信与附信 | 只澄清会影响当前路由的歧义 |
| 已发表论文的技术异议 | 读ch14，定位主张、证据和影响 | 评论程序与篇幅由目标刊物决定 |
| 综述要转成研究Letter | 先评估是否具备原创结果 | 文体转换会改变证据要求 |
| 系统综述要投综述类期刊 | 核查该刊是否接收该子类型 | 方法合格与栏目适配分别评价 |
| 用户只要求改几句话 | 选相应文体并局部编辑 | 完整起草流程按实际任务需要启动 |
| 比较指定论文或补充背景 | 读[调研指南](references/research-workflow.md) | 先盘点已有材料，再选比较或补检深度 |
| 检索结束依据不清 | 依调研指南做覆盖审查 | 记录完成范围、停止原因和缺口 |
| 引用可查，句子依据仍不清 | 读[核验指南](references/claim-verification.md) | 检查实际版本、原文定位和支持度 |
| 调研或写作跨会话继续 | 用[简报续接记录](assets/writing-brief.md)核对材料 | 文件版本变化时复核受影响部分 |
| 只有大主题，没有具体回答 | 用ch01的Topic—Question—Significance收敛 | 说明知识后果，再定位贡献和证据 |
| 数据可信，仍不清楚为何支持结论 | 用ch01的Warrant五问检查推断桥梁 | 相关性与证据真实性分别处理 |
| 需要学习目标文章的节内安排 | 读[功能建模](references/genre-modeling.md) | 根据同文体样例建立可调整模型 |
| 句子各自通顺，整段仍跳跃 | 用ch11的旧—新信息诊断 | 句首先承接读者已知内容 |
| 只有分类/算法指标 | 限定到该指标与测试条件 | 物理灵敏度需要额外证据 |
| 文献数量多、问题仍宽 | 考虑范围/叙述综述 | 先描绘概念与条件 |
| 问题明确且有可执行协议 | 设计系统综述 | 实际过程和日志决定可报告内容 |
| 同类结果定义或数据依赖不同 | 先做可比性表 | 决定分组、定性综合或专门组合 |
| 作者要求PRISMA“认证” | 提供报告清单及缺口 | 清单不能认证实施质量 |
| 综述段落按作者逐篇排列 | 改为主题/争议综合 | 需要跨研究判断 |
| 目标是Nature Article | 读当前作者指南 | summary paragraph有专用规则 |
| 目标是CERN Yellow Reports会议稿 | 读该刊摘要和投稿要求 | 与Nature的摘要规则不同 |
| 不清楚“会议报告”的含义 | 结合上下文判定，必要时确认 | 演讲与参会总结产出不同 |
| 想靠标题提高引用 | 比较准确性、信息量和检索性 | 观察性相关无法保证引用收益 |
| 结果只在模拟中得到 | 保留模拟/预期条件 | 避免变成实验观察的主张 |
| 有局部显著性，缺全局信息 | 保留局部表述并列核实项 | 扫描会影响整体解释 |
| 需要数字或图，但材料未提供 | 标记具体缺口并完成其余部分 | 数值必须来自实际证据 |
| 英文流畅，主张强度变化 | 回查条件与限定词 | 科学含义优先 |
| 审稿回复声称已补分析 | 依[复核指南](references/revision-audit.md)拆分承诺并核对 | 报告实际证据、完成状态与剩余动作 |
| 需要提交或给别人发送 | 准备可审查材料后依授权行动 | 技能不会自动授予发送权限 |
