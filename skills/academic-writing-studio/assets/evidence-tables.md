# 文献、主张、检索与综合表

按任务复制需要的部分，由助手从已有材料整理。文献ID与主张ID在各表间复用；已有信息用ID回链。判断规则见[调研指南](../references/research-workflow.md)和[核验指南](../references/claim-verification.md)，空缺与已核实信息分开记录。
