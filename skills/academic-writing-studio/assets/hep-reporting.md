## 共同信息

- [ ] 过程/末态/模型/可观测量与文章贡献清楚。
- [ ] 符号、单位、理论/数据/软件版本一致。

## 实验与统计

- [ ] 碰撞系统、能量、数据时期、积分亮度。
- [ ] 对象、触发、选择、区域与背景估计/验证。
- [ ] MC与校准，归一化、接受度/效率、相空间与展开。
- [ ] 统计和系统不确定度、相关性、参数处理。
- [ ] 方法、置信水平、observed/expected与局部/全局含义。
- [ ] 图中误差带、归一化、bin、单位和参考线有定义。

## 理论、唯象与工具

- [ ] 假设、约定、适用域、扰动阶数和近似。
- [ ] 适用的尺度/PDF/标准输入、参数与不确定度。
- [ ] 已知极限、稳定性/收敛、交叉检查与公平基线。
- [ ] 重解释验证、统计假设、模型限制与失效条件。

## 综述、共享与报告状态

- [ ] arXiv/期刊/会议版本与更新关系已记录。
- [ ] 测量定义和相空间可比较；共享数据/误差依赖已处理。
- [ ] 公开表、误差/相关信息、代码/似然资源与限制如实说明。
- [ ] 图表来源、结果状态、作者/合作组署名和公开范围有依据。
