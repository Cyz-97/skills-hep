# 学位论文、书章、技术报告与研究计划

本章为编译者原创的体裁比较；B5第29章提供书章这一类型的来源背景，B4试读支持读者角色与沟通目标的区分。尚未读到的书籍专章不作为细则依据。

| 体裁 | 组织重点 | 应核查的要求 |
|---|---|---|
| 学位论文/博士论文 | 持续的研究问题、方法能力、各章贡献和整体综合 | 学校模板、章节关系、已发表内容重用、独立贡献 |
| 研究型书章 | 与全书目标一致的专题论证 | 编辑给定范围、读者、交叉重叠、图表许可 |
| 教学型书章 | 概念顺序、前置知识、例子与练习 | 读者水平、术语表、符号一致性、学习目标 |
| 技术报告/内部说明 | 让同事复核或继续工作 | 数据/代码版本、假设、配置、检验、已知问题与状态 |
| 研究计划/基金申请 | 重要问题、可行方法、成功标准、风险与替代路线 | 资助方/机构指南、实际初步证据、资源与进度 |
| 进展报告 | 目标与实际进度对应 | 已完成工作、证据、偏离、后续任务与依赖 |

## 学位论文的整体性

建立章节关系图：共同问题、各章子问题、方法或证据、独立贡献、总讨论。论文合集型结构仍需解释章节之间的关系、重复内容及共同限制。根据学校规范区分已发表章节与原创综合。

文献综述章服务于研究问题和方法选择；总讨论跨章比较结论、冲突与适用范围。只完成局部论文时，整体命题的未验证部分明确标出。

## 研究计划的可信度

按`目标 → 支持目标的理由 → 方法/工作包 → 可检验里程碑 → 风险与替代方案 → 预期价值`组织。区分已有数据与预期结果；预算、样本规模与工作量来自实际输入。可先形成待补证据的计划骨架。

## 原创示例

HEP分析说明可以按样本/软件版本、选择、背景方法、误差、统计、交叉检验和开放问题编排。对外短论文只保留支撑公共论证所需的信息，并按合作组规则引用获准公开的材料。

完成条件：读者知道文本要支持哪种判断或行动；每个成果/计划的状态准确；篇幅与结构符合指定机构或编辑要求。
