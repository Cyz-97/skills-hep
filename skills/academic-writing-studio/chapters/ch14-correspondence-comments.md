# 致编辑信、发表后评论、回复与更正

依据：[类型指南](../references/genre-guidelines.md)G1、G2、G4–G6。具体评论程序与长度由目标刊物决定。用户说“letter”时以刊物及科学目的判断；仅歧义影响当前任务时澄清。

## 四条路径

| 实际目的 | 路径 | 必需信息 |
|---|---|---|
| 对研究相关议题或杂志内容表达简短意见 | Correspondence / Letter to the Editor | 清楚议题、单一论点、必要事实与简洁建议 |
| 对特定已发表论文提出科学挑战或澄清 | Comment / Matters Arising等 | 对象与原主张、可复核问题、证据、影响范围 |
| 回应已提出的正式评论 | Reply / Response | 逐点回应、澄清或修正、支持依据 |
| 修正本人已发表工作的错误/遗漏 | Correction / Erratum等 | 原文位置、准确修正、受影响结果及结论 |

栏目功能需再核对：Nature的Correspondence与Nature Reviews的同名栏目用途不同。原创研究短文转ch12；随稿投稿信与审稿回复转ch09。对审稿人的回复和对已发表Comment的Reply具有不同对象与流程。

## 发表后技术评论

1. 定位被评论论文的版本、具体主张、公式/图表或方法。
2. 判断问题是可复现错误、解释分歧、假设遗漏，还是依赖后续发展才出现的新认识。
3. 展示可核查推导、数据或反例；说明问题影响哪些结果以及哪些结论仍成立。
4. 给出建设性澄清或修正方案，语气围绕科学内容。
5. 在投稿准备范围内核查评论期限、篇幅、原作者沟通和回复程序等要求；实际联系或提交遵循用户授权。

对别人工作有异议并不自动满足该刊Comment标准；需要主张和证据的具体对应。无法取得足够原文或复核材料时，交付问题清单和需核查位置。

## Reply与更正

Reply先列出评论的科学要点，再回应其证据和对原结论的影响。需要改变原文时准确说明；新增结果能否纳入按栏目规定处理。

更正先核对准确替换内容与影响面。相应数值、公式、图和结论逐项对齐；原因、修正与后续核查状态如实陈述。涉及更正或撤稿程序的问题按出版方现行流程准备事实材料。

## 原创示例

读者发现一篇HEP论文的两个推导使用不同的归一化约定。先定位约定与公式，验证差异能否通过换算解释；若仍不一致，说明影响的结果和修正。短评不能从一个局部问题直接断言整篇论文失效。

完成条件：文体、评论对象与论点明确；证据和影响可定位；回应覆盖实际提出的问题。仅有草稿和待核实项时保留其状态，不声称已联系作者或已完成复核。
