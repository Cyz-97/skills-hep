# 原创研究Letter与其他研究短格式

适用：PRL Letter、PRD Letter、Research Letter及其他明确报告原创研究的短格式。具体栏目定义先查[类型指南](../references/genre-guidelines.md)G1–G3。致编辑信、Comment和投稿附信分别转ch14、ch09。

## 类型目的与结构

Letter在相应研究栏目中报告原创结果，保持完整可评价的科学论证。短篇幅要求突出核心贡献、适当选择背景和细节；具体重要性、受众和处理政策由目标刊物定义。一般短文与Letter名称相近时，仍需核对栏目，不能假定完全等价。

建议骨架：`具体问题与重要性 → 最接近工作留下的缺口 → 核心研究做法 → 关键结果和可靠性 → 新认识与适用范围`。这些功能可由连续段落承担，也可依期刊规范设小标题。

## 起草与压缩

1. **确定中心贡献**：用一句话说明得到什么认识、为什么值得该栏目读者关注。多项结果若支撑共同贡献，可组成一条证据路径。
2. **缩短背景入口**：保留理解问题和评价贡献所需的知识，解释最接近研究与本文差别。PRL按较广物理读者组织，专业刊Letter按其实际受众调整。
3. **保留评价所需信息**：主要定义、条件、研究设计/推导思路和关键验证在核心文本可理解；专业细节按刊物规定安排到附录、End Matter或补充材料，并交叉引用。
4. **以结果支撑贡献**：选择直接回答问题的图组或推导，保留影响结论的不确定度、对照、稳健性与限制。删去重复叙述和次要支线。
5. **收束意义**：清楚指出比既有工作多知道什么，以及结论何时成立。科学意义与后续设想分别表达。
6. **核对格式和提交理由**：采用具体期刊的词数折算、图表与附录要求；需要说明短格式适配理由时结合ch09准备投稿材料。

## 从完整Article改写

先画出原稿的主张—证据关系，再选择Letter要承担的贡献。可减少铺垫、合并重复图文、缩短次要应用；对核心结论必要的检验和限定仍须可评价。篇幅无法容纳完整论证时，考虑保留完整Article或重新界定短文范围。

日后扩展为长篇时，记录短文与新稿的结果重叠、实质增加的信息/分析及新增认识，遵循具体刊物的重用和披露要求。G2对PRD长篇扩展有明确要求，不能把单纯增加字数当作充分增量。

Review或Perspective转研究Letter需要可支撑原创贡献的研究结果；仅精简文献综述文本无法建立这类证据。可先评估现有材料是否满足目标栏目，并列出所需研究或更合适的文体。

## 原创示例

一篇HEP研究包含新推导、多个参数扫描和工具实现。若短文主要贡献是一个新的物理界限，可围绕推导条件、界限与必要验证组织正文；大规模扫描和工具细节按栏目许可安排。压缩后若读者无法理解界限依赖哪些假设，就需补回说明或调整目标格式。

## 完成条件

- 核心贡献、比较对象及主要支持证据可定位。
- 读者可从正文理解主要结果的成立条件；专业细节的位置和作用明确。
- 原创研究Letter、致编辑信、评论和附信的身份没有混用。
- 格式适配任务已按对应指南检查词数折算；未进行格式适配时如实注明范围。
