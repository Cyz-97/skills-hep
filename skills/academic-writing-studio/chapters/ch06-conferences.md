# 会议摘要、论文、口头报告、海报与参会总结

主要依据：B5第27章、B3-8第27–29章及H2。演讲与海报规划为跨来源综合；具体刊会规则与当前研究状态优先。

## 先确定交付形式

| 形式 | 核心任务 | 必需内容 |
|---|---|---|
| 会议摘要 | 供项目委员会判断主题与贡献 | 问题、方法、实际结果/阶段、意义 |
| Proceedings paper | 留下可引用的会议贡献 | 自洽论证、必要方法、结果与文献 |
| Oral talk / 口头报告 | 在有限时间使听众理解和记住贡献 | 核心问题、关键证据、解释与问答 |
| Poster | 支持走近阅读及面对面讨论 | 清晰入口、主要图组、可扫描文字 |
| Attendance report / 参会总结 | 为同事整理会议的新进展与行动 | 会议信息、专题综合、来源、后续任务 |

“会议报告”含义不明确时先根据上下文判断；仍影响产出时确认是会议论文、口头报告还是参会总结。

B3-8第29章中的conference report主要讨论收入proceedings的会议贡献；该名称也可能被用户用于口头报告或参会总结。按实际交付物和出版地位判断其要求。

## 摘要与会议论文

开展会议稿起草、格式适配或投稿准备时读取call for papers、页数/词数、匿名要求、模板、已发表/预印本和期刊扩展政策；局部语言编辑先完成指定内容。确认会议论文在该领域的出版地位：部分领域会议论文属于完整的同行评议成果；某些会议只收简短进展。B5的领域经验不能直接推广到所有会议。

短论文保留完整的问题—方法—结果—意义链条。压缩背景和次要细节，必要方法可指向已发表协议；读者仍应能评价主要结果。说明与既有论文、会议摘要或后续期刊稿的关系，处理重用内容和图表授权。

## 口头报告

1. 明确听众基础与总时间；为问答留出主办方规定时间。
2. 用一句话确定希望听众记住的结论，选取直接支撑它的图组。
3. 开头提出值得回答的问题，中间按证据推进，结尾回到问题与意义。
4. 每页围绕一个信息目的；详细推导、备用检验和额外图放备份页。
5. 给出时间预算并注明估算依据；有实际演练记录时再按耗时和反馈删减。页数依内容密度与演讲速度调整。

向专业同行可保留必要技术细节；跨领域报告先解释物理对象与指标。口头讲稿要写出过渡和图的阅读顺序，不能只复述幻灯片文字。

演练时整理最可能的科学质疑及对应证据、限制和备份图；问答后把有效问题回填到稿件的定义、论证或限制中。未解决的问题记录为待核实项，后续答复依实际证据与授权处理。

## 海报与参会总结

海报先明确观看距离、尺寸和使用场景。使标题、问题、主要结果和图的阅读顺序在快速浏览时可辨；用短节和图组支持深入讨论。预备不同长度的口头介绍；二维码只连接用户允许分享且已可用的材料。

参会总结按主题归纳多个报告间的一致、差异和未决问题。每项结果标明报告人、标题、时间、可访问链接及preliminary/已发表状态。区分报告者观点与自己的判断；从用户提供的实际记录出发。

完成条件：交付形式明确；核心贡献可在开头与结尾定位，主要图组能对应支撑证据；时长/字数要求在本轮适配范围内已核对，估算与实测明确区分。模板见[会议规划表](../assets/conference-planner.md)。
