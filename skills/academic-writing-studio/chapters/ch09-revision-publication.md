# 期刊定位、投稿与修改

主要依据：B5第19–26章（CC BY 4.0改编）、B3-8第41章已读选段；N3的目标读者与期刊匹配建议。所有具体出版政策以目标刊物现行指南为准。

本章cover letter为随稿附信，reviewer response为审稿过程回复。可公开发表的原创研究Letter、致编辑信和发表后Reply分别读[ch12](ch12-research-letters.md)、[ch14](ch14-correspondence-comments.md)。

## 选择载体与准备投稿

先比较研究主题、读者、贡献层次与文章类型；查看最接近文献的发表载体和近期同类文章，再核对范围、格式、篇幅、审稿模式与数据要求。用户要求投稿推荐时联网检索当前信息，提供匹配理由及可能的不足。

投稿信说明问题、贡献、对目标读者的价值、与最接近工作的差别，以及刊物要求披露的相关稿件或利益冲突。避免只重复摘要。作者、署名、授权、数据和声明依据实际事实填写；缺失信息留待确认。

## 三轮修改

1. **科学与结构**：检查研究问题是否得到回答，主张是否有证据，关键反例与限制是否得到处理；用反向提纲调整顺序。
2. **段落与语言**：检查段落功能、逻辑过渡、术语和信息负担。对于意义可能改变的修改保留作者核实标记。
3. **一致性与格式**：对齐标题/摘要/结论、数字/图表/补充材料、参考文献和版本；最后应用期刊模板。

## 审稿回复

使用[回复表](../assets/reviewer-response.md)。每点说明理解、回应、实际改动和位置；新增分析给出结果及其对结论的影响。需要按意见大修、审查现有回复或验证修订稿时，执行[复核指南](../references/revision-audit.md)，按关切、承诺和实际证据逐项检查。

| 情况 | 回应方法 |
|---|---|
| 同意并修改 | 明确改了什么、为何解决问题、具体位置 |
| 原文不清导致误解 | 说明澄清，并展示修改后的关键文本 |
| 无法补充分析/数据 | 如实说明限制、理由和对结论的影响；可考虑收窄主张 |
| 有证据支持不同判断 | 礼貌呈现论点与依据，回应评审关切，并澄清文章 |
| 多位评审要求冲突 | 说明兼容方案，必要时把待编辑裁定事项列清楚 |

“已完成”“已添加”“已上传”仅用于实际完成的动作。页码/行号从最后一份稿件取得；尚未生成最终版时使用节名和标记，不编造定位。

## 校样与发表后

校样重点核查姓名、单位、公式、上下标、单位、表格对齐、图和参考文献。涉及科学结果的改动依编辑流程处理。公开版本与代码/数据标识保持一致；发现错误时准备更正事实与影响说明，发送或发布需用户授权。

原创示例：评审要求外推到未测相空间，现有数据不足。回复可解释限制、增加适用范围声明并删除过宽结论。完成条件是稿件真实回应了关切，而回复信与正文相互一致。
