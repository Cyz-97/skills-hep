# 研究论证与文章规划

核心：读者需要理解问题的价值、研究的回答及回答成立的条件。来源：B1第4章（印刷页26–34）、B4第5版试读导论；本轮增补B4-4第3–4、7、9、11章及B2 §4.2.3。版本见[来源目录](../references/sources.md)；操作与HEP例子为跨来源综合。

## 将主题变成可评价贡献

用Booth等人的Topic—Question—Significance三步明确研究：研究什么对象；要回答什么具体问题；回答后能帮助读者理解什么。问题的condition是尚不理解的状态，consequence是它阻碍的更重要理解。基础研究可以解释知识上的后果；应用研究再说明对行动或决策的影响。

据此写清：现有研究为何不足；本文给出的具体回答；这个回答改变何种理解、方法或决策。把“研究较少”转为有后果的缺口。区分研究完成了什么（achievement）与它对已有认识增加了什么（contribution）；“做了新计算”还需说明计算解决了哪项判断。新数据、新方法、新解释、检验已知命题分别有不同贡献要求。

重要主张用一行证据链登记：`主张 → 直接证据/推导 → 推断依赖的假设 → 最强替代解释 → 可适用范围`。主张无法指向证据时，收窄措辞或规划缺失分析。

## 理由、证据与Warrant

Booth等人的论证要素包括claim、reason、evidence、acknowledgment/response和warrant。reason回答为何接受主张，evidence支撑理由；warrant是把理由连接到主张的一般推断原则。读者接受数据却不接受结论时，分别检查数据是否可靠、推断是否相关。补充同类数据只能处理其中部分问题。

需要解释推断桥梁时，把warrant写成“在条件X下，可由理由R推到结论C”，依B4-4 §11.4检查五点：原则是否合理；限定是否足够；与竞争原则相比是否有依据；是否适合该研究领域；本例的理由和结论是否确实落在原则覆盖范围内。

跨领域读者难以理解或可能质疑该桥梁时，在证据附近说明；同行共有且无争议的前提可简写。前提本身有争议时，将其作为需要依据的主张处理。

## OCAR：按功能组织叙事

Schimel将科学叙事划分为Opening、Challenge、Action、Resolution：交代读者所需背景，提出具体问题，说明研究如何应对，解释由此获得的认识。用于检查全篇与段落的功能；各元素长度和排列可适应载体，摘要可提前呈现发现。

OCAR用于信息组织。结果必须保留真实复杂性；矛盾证据、无效结果和限制按其对主张的影响呈现。

## 提纲与诊断

1. 给每节写一句“本节读完后读者知道什么”。
2. 安排关键图、表、论证或文献组；删去无法说明作用的背景。
3. 标记读者可能提出的反对意见，将回答安排到相应证据之后。
4. 写出结论能覆盖的最宽范围，再检查标题、摘要与讨论是否越界。

完整起草或实质性重构时，用[写作简报的提纲](../assets/writing-brief.md)保存精简论证骨架，主张ID回链证据与最强替代解释；后续写作和结构检查复用该骨架。新颖性判断需要检索依据时，按[核验指南](../references/claim-verification.md#新颖性与缺失主张)限定查找范围并比较最接近工作。

已有全文时做反向提纲：每段只写功能与核心主张。相邻段落功能重复则合并；依赖前提尚未出现则调整顺序；跨节重复用交叉引用处理。

## 原创示例

控制区中的闭合检验支持“该模型在此控制区与观测相容”。要进一步支持信号区背景预言，还需说明控制区与信号区之间的迁移依据及其验证。Warrant检查可暴露过程组成、运动学条件或误差模型变化造成的适用范围缺口；增加控制区统计量本身无法验证所有迁移假设。

完成条件：核心贡献可用一句话表达；每项主要结论有来源定位；读者知道哪些条件变化会削弱结论。
