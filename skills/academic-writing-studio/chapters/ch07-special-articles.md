# 方法、软件、数据、协议及其他特殊文章

本章为编译者对贡献类型的原创路由与检查表。B5只提供一般论文沟通基础；本章不声称这些类型均在所读书籍中得到专门讲解。需要确定栏目资格、适配格式或准备投稿时读取目标出版物的对应指南；局部语言编辑按用户指定范围完成。

| 类型 | 需要回答的问题 | 文章中的证据重点 |
|---|---|---|
| 方法/技术论文 | 新方法解决何种既有限制？ | 原理、适用条件、基线、稳健性、成本与失败场景 |
| 软件论文 | 软件让哪些任务变得可行或可靠？ | 功能/设计、验证、版本、使用示例、许可证与维护范围 |
| 数据描述论文 | 数据为何有价值且可复用？ | 生成、清洗、技术验证、结构、元数据、访问与使用限制 |
| Protocol / 研究方案 | 如何实施与评价计划中的研究？ | 目标、设计、流程、分析计划、可行性及必要审批 |
| Registered Report | 在结果出现前能否评价研究设计？ | 问题与方法的预先审查、阶段要求和偏离记录 |
| Replication / 验证研究 | 原结果在哪些条件下可重现？ | 复现目标、偏离、检验能力、比较尺度与不确定度 |
| Null / negative results | 这些结果能排除多大的效应或哪些解释？ | 灵敏度、区间、质量控制与分析限制 |
| Case study / 案例研究 | 一个受限实例提供何种可解释信息？ | 案例选择、情境、证据链、可迁移范围与适用伦理 |
| Tutorial / Pedagogical review | 读者读完能理解或完成什么？ | 前置知识、概念层级、原创例子、常见误区和练习 |

## 操作方式

先从贡献列选定主要类型；跨类型稿件确定哪个贡献主导审稿标准。例如“使用公开软件得到物理结果”的稿件可能仍以物理发现为主，软件实现细节应服务该目标。方法、软件和数据说明贡献性质；具体出版格式还可能是完整Article或研究型Letter，分别组合读取[ch02](ch02-research-articles.md)或[ch12](ch12-research-letters.md)。

观点、展望和路线讨论读[ch13](ch13-perspectives.md)；致编辑信、发表后评论和Reply读[ch14](ch14-correspondence-comments.md)。

写方法或软件优越性时核查任务、数据、硬件、预算、超参数和评估指标的可比性；报告适用条件和失败情形。数据论文的技术验证与使用建议不自动构成新的物理解释。

Protocol与Registered Report按实际研究阶段写作。已知结果、计划分析与事后修改分别披露；已完成研究不能重写成事前承诺。若需要具体注册或期刊要求，检索官方指南并注明版本。

原创示例：新展开算法的贡献是估计性能与稳定性，就需要闭合检验、模型依赖、正则化敏感性和误差传播；只展示一个更平滑的分布不足以确认改进。

完成条件：文章类型与核心贡献一致；验证方式能直接检验该贡献；体裁特有要求有目标出版物依据。
