# 文献综述、系统综述与证据综合

核心：围绕问题比较研究、解释差异并给出有边界的综合判断。主要依据：B6第1、3–8章，B5第28章；均为CC BY 4.0改编。系统/范围综述额外参考R1、R2。

## 区分综述文章与其他文体

Review综合并评价既有研究。原创研究以新的实验、理论或计算结果为中心；Perspective围绕作者立场或方向展开，见[ch13](ch13-perspectives.md)。综述综合也可产生新的认识或定量结果；因此文章身份应按研究目的、方法和具体栏目判断。

先辨认下表子类型，再决定检索、评价与报告深度。编辑已有综述段落时先完成指定范围；以下完整流程用于需要开展相应综述工作的任务。

## 选择综述类型

| 目标 | 类型 | 应报告什么 |
|---|---|---|
| 解释领域、概念和研究路线 | 叙述/主题综述 | 范围、选文逻辑、核心争议、综合观点 |
| 检验假设或理论基础 | 批判/整合综述 | 评价标准、冲突证据、综合框架 |
| 比较技术、器件、方法或性能 | 技术综述 Technical Review | 条件、评价维度、性能/局限与适用范围 |
| 聚焦一个受限主题或近期进展 | 短综述/进展综述 Mini-review / Progress | 窄范围、选文逻辑和关键变化；具体名称和篇幅按刊物 |
| 回答明确、受限的问题 | 系统综述 | 协议、可复现检索、筛选、质量/偏倚评价与综合 |
| 描绘研究范围和概念分布 | 范围综述 | 范围问题、来源与纳排、数据提取和证据图谱 |
| 合并可比较的定量结果 | 元分析 | 效应定义、数据依赖、模型、异质性、敏感性及不确定度 |
| 综合已有综述 | 伞状综述 | 综述质量、原始研究重叠、证据一致性 |
| 分析出版物和引用网络 | 文献计量综述 | 数据库、查询、清洗、覆盖偏差和网络设定 |

元分析可能属于系统综述的一部分；并非每项系统综述都能合并数值。主题尚未稳定时先做范围探索，再决定是否适合系统综述。文献计量图无法单独证明科学结论或研究质量。

## 按类型组织正文

| 子类型 | 可采用的论证骨架 | 完成时核查 |
|---|---|---|
| 叙述/批判/整合Review | 问题与范围—主题/理论比较—一致与分歧—综合框架—未决问题 | 覆盖与选择有解释，每个主题有跨文献判断 |
| Technical Review | 技术问题—方法分类—共同评价维度—条件化比较—适用建议 | 对象、指标、实验条件及局限可比较 |
| Mini-review / Progress | 明确边界—关键研究变化—当前判断—尚待验证环节 | 不把受限范围声称为全领域全面覆盖 |
| 系统综述 | 问题—可复现方法—筛选和研究特征—质量/偏倚评价—综合—限制 | 实际方法和流程数量有记录，未做事项如实说明 |
| 范围综述 | 范围问题—来源/纳排/提取—证据分布—概念与缺口 | 映射结果和类型目标一致，效果推断有相应依据 |
| 含元分析的综述 | 问题/方法—研究特征—模型化综合—异质性与敏感性—解释 | 合并量、依赖和模型假设可核查 |

以上骨架为B5、B6及报告规范的原创综合；Technical Review、Progress等栏目功能见[类型指南](../references/genre-guidelines.md)G6。综述类型与期刊接收范围分别核查，例如Nature Reviews该指南不接收系统综述或元分析；选择其他载体或调整文体需要向用户说明依据，并保留实际方法身份。

## 从调研到综合

需要实际检索、筛选和提取时，执行[调研指南](../references/research-workflow.md)，用[证据表](../assets/evidence-tables.md)保存语料、选择理由与覆盖结果。已有材料足以完成指定段落时直接综合，实际读取范围依[核验指南](../references/claim-verification.md)记录。

正式综述按子类型确定检索、纳排、实际筛选/复核方式、提取字段、质量/偏倚评价和综合方法；需要注册时按领域与载体规则处理。方案修订保留理由，流程计数来自实际记录。HEP的问题和评价维度采用过程/模型、测量量、数据条件、方法及假设，依据研究设计选择适合的可靠性判断。

PRISMA 2020用于系统综述的透明报告；PRISMA-ScR用于范围综述报告。清单不能替代研究方法，也不能证明实施质量。未实际完成双人筛选、注册或偏倚评价时如实说明现有流程。

## 综合段落的构造

`主题判断 → 多项研究的一致/冲突证据 → 方法或条件比较 → 对研究问题的含义 → 剩余不确定性`。先建立证据表，再写段落，避免逐篇复述造成作者名单式结构。

原创示例：两项喷注标记研究的AUC不同，先比较对象定义、训练样本、工作点、验证域和背景过程。无法确认可比性时分别叙述，列出差异；物理灵敏度还依赖产额和系统误差。

## 元分析与HEP特别检查

合并前核实被合并量、单位、定义及相关性；记录共享样本、重复发表、同一合作组的更新与组合结果。模型、相空间或数据依赖不兼容时选择分组、定性综合或可说明假设的专门组合。实际统计实施需要对应专业方法支持。

完成条件：正文中每个综合结论可追溯到一组已读文献；读者能理解研究为何纳入、为何分组、为何得出该判断。检索的实际完成范围、停止依据和剩余缺口有记录；结论受这些限制约束。
