# 修订与审稿回复复核

适用：按意见大修、检查现有回复信、验证修订稿或比较修订前后。投稿与回应策略见[ch09](../chapters/ch09-revision-publication.md)，填表用[审稿回复工作表](../assets/reviewer-response.md)。方法参考A1；归属见[来源目录](sources.md)。

## 确定本轮范围

只要求审查回复信时，交付覆盖与证据缺口；实际修改稿件时按授权范围处理。完整复核需要原始意见、原稿、修订稿及现有回复；缺少某项材料时先完成可查部分，明确哪些判断仍无法核实。页码和行号取自实际被检查的版本。

## 复核步骤与完成标准

1. **拆开关切和承诺。** 保留原始意见及编号，将复合问题拆成可回答项。分别记录评审的要求、作者的决定/理由、回复信声称已做的动作及计划中的动作；一项意见可对应多个承诺。完成时：每项实质关切有去向，计划与完成状态可辨认。
2. **确定检查依据。** 从原始关切及编辑要求提取可观察的满足条件，说明所需证据和稿件影响；尊重有证据的异议、等效修改与实际无法完成的限制。完成时：逐项能说明什么证据足以回应，格式偏好与科学有效性问题已区分。
3. **核对真实改动。** 比较原稿、修订稿和实际新增分析，检查证据是否满足上述条件，再逐项核对回复信的陈述。新增实验/分析对应结果与限制，澄清对应新文本，文献补充对应引用及支持关系。完成时：每个声称完成的承诺有具体证据，证据位置与版本相符。
4. **检查回归与遗漏。** 对修改部分及其依赖的标题、摘要、结论、图表和补充材料检查一致性；数字、公式、符号、引用和主张范围依[主张核验指南](claim-verification.md)复查。将修订引入的问题、原稿已有但此次新发现的问题、来源不清的问题分开报告。完成时：相关影响已核对，新增问题有前后稿依据或不确定说明。
5. **交付逐项结果。** 报告每项意见和每个承诺的处理情况、证据、复核结论及剩余动作；需要修改时使回复与稿件实际状态一致。完成时：逐项结果覆盖本轮范围，尚待作者判断和待完成动作可定位。

## 复核结论

| 结论 | 使用条件 |
|---|---|
| 完整回应 | 实际证据满足关切，或有依据的异议已回答该关切；具体方式写明 |
| 部分回应 | 完成部分要求，指出已满足与剩余部分 |
| 未回应 | 关切尚无对应回应或实际改动 |
| 引入退步 | 有前后稿证据说明修改使相关问题恶化 |
| 无法核实 | 缺少必要版本、结果或定位；列出缺失材料 |

作者有理由不采纳某项要求时保留理由，评价它是否回应评审关切；作者决定与复核判断分别记录。完成条件沿用原始关切，新提出的标准明确标为新建议。科学有效性、目标刊物匹配与材料准备情况各自说明；AI内部复核作为修改支持，接收与发表结果由实际编辑和评审过程决定。

同一助手在当前会话中依上述顺序复核，标为内部复核，并说明实际检查范围。原文中的角色名称、分轮检查或一句“已核验”均不足以证明独立评审或完整科学验证。

## 原创示例

评审要求“补充基线并报告误差”，修订稿增加一张基线图，回复称两项都已完成。拆成两项承诺：基线比较按实际图与条件评价；误差分析检查方法、结果和正文报告。缺少后者时记为未完成，整条意见为部分回应；回复可写已补基线，并如实说明误差分析的现状和后续选择。
