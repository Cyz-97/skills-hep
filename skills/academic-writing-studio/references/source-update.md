# 增补原文与更新技能

仅在用户明确要求扩充或维护academic-writing-studio的长期知识库时执行。为当前写作提供的书籍、论文和笔记作为本次任务材料，相关证据与笔记保存在当前任务中。已有明确增补授权时继续完成，无需重复询问。

1. 确认文件、作者、版本、目录、原文访问范围及许可。与已有版本区分；无法读到的章节保持待补状态。
2. 先保存原件到当前任务的工作区，再用book-to-skill可用提取器提取。PDF公式、表格或图形影响结论时做视觉核查；记录未读取的图片。
3. 超长文档按目录、章节或主题检索，保留章名、印刷页与PDF页的区别。自动章节识别仅用于发现线索。
4. 输出短篇提取卡：命名框架、适用条件、行动步骤、反例/边界、来源位置。新模板与自创示例标明原创。受版权保护内容保持精简改写，原件留在工作区。
5. 把候选方法映射到现有模块，分别标记新增判断、已有内容细化、仅补来源或不采用。同一规则在一个位置维护，其他模块用条件指针引用；只有独立用途确实需要时新增参考文件。内容冲突时比较文体、学科、年代和证据级别。刊物现行规则优先于一般经验；统计关联不能推出写作干预的因果收益。
6. 更新sources.md与受影响模块；说明覆盖范围是否从目录/试读升级为全文可用，以及实际精读了哪些部分。
7. 校验内部链接、前置元数据、归属和行为例子。再次运行官方技能校验器与book-to-skill安全扫描。若扫描报出问题，保留发现并请人核查，按扫描工具要求处理。
