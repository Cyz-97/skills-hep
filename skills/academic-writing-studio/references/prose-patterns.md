# 减少模板化与空泛表达

起草、润色或翻译时，随本轮编辑检查下表；只修改当前文本中影响准确性或可读性的表达，直接交付所需稿件。用户要求诊断时再列位置与理由。

这些模式是阅读与修改线索，不能用于判断文本是否由AI生成。按上下文判断表达的作用，词语本身不构成删除依据。

| 常见模式与线索 | 修改目标与适用边界 |
|---|---|
| 套式开头：“近年来……受到广泛关注”“随着……快速发展” | 直接交代研究对象、具体问题或有依据的变化；背景确实涉及时间趋势时保留其事实与来源。 |
| 夸大意义与新颖性：pivotal、groundbreaking、反复强调novel、泛称“填补空白” | 说清具体贡献、相对已有工作的差异及适用范围。首创性与优越性须有相应依据；研究计划的愿景按可行性与文体要求表达。 |
| 空泛强调与华饰：“值得注意的是”、Importantly、delve、underscore、seamless等 | 直接写有信息的事实或动作；词语承担精确的专业含义时保留，如统计术语leverage。 |
| 模糊规模或程度：extensive、numerous、“广泛”“相对较好”“某种程度上” | 用材料已有的数量、比较对象或条件说明范围。缺失信息按[ch11的科学不变量](../chapters/ch11-language.md#修改时的科学不变量)处理；保留证据支持的不确定性限定。 |
| 机械衔接与排比：连续Moreover/Furthermore、反复三项罗列、套式反差句 | 让句间关系承担衔接，直接说明比较、因果或让步。各项确有独立贡献、反差确属论点时保留相应结构。 |
| 同一对象轮换近义词，造成概念漂移 | 同一科学对象使用稳定术语；需要区分的概念明确给出各自名称。 |
| 从句层层堆叠，句末用“highlighting/underscoring…”追加笼统评价 | 按主张边界分句，写清动作与指代；尾句确有推理作用时交代依据，并保留限定与逻辑关系。 |
| 贡献清单只列“新方法、充分实验、优秀结果” | 每项说明具体产物、发现或验证范围；已有事实不足以补全时标明缺口。 |

科学含义、证据强度与中英文转换统一依[ch11](../chapters/ch11-language.md)处理。数学证明、专业术语、必要被动语态和第一人称按学科语境保留；调整措辞前核对其实际含义。

完成条件：每处修改有明确的信息或可读性收益，术语与论证保持连贯，涉及科学含义的变化按本轮要求单列。
