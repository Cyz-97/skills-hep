# 高能物理科研绘图

## 任务边界

把上游提供的最终物理结果绘制为科研图，或审查现有图。项目提供数据对象或最终缓存、实验元数据、既定归一化与误差定义、可用工具和运行方式；项目配置、环境、缓存协议与上游物理计算由各自流程负责。

绘图输入只读：保持中心值、权重、归一化及误差语义，不重新拟合或推导物理结果。显示变换只用于表达既定结果，并对中心值和误差一致应用。发现科学上必需的输入缺失或语义不明确时，说明缺项并交回上游。

用户当前要求和适用的项目规范优先，其余遵循本 skill。数据表达、布局和输出的详细规则统一维护在 [绘图规范](references/plotting-standard.md)，视觉检查方法维护在 [视觉抽查](references/visual-review.md)。

## 工作流程与完成标准

### 1. 输入就绪

列明请求的图，识别图类型、输入来源、计数/密度、绝对/形状比较、样本身份和误差来源。上下文已明确时直接使用；缺少非关键元数据时省略相应字段。输入字段和显示变换需要细则时读绘图规范 §2；使用 DataFactory 时读 §3。

Notebook 默认在结果生成后的独立 cell 从内存直绘；缓存重绘、批处理或独立展示消费项目提供的最终缓存。物理计算与渲染可以处于同一文件的不同 cell，职责边界位于绘图 cell/代码段。

**完成条件：** 每张请求图都已找到足够输入，或已记录缺项和影响；缺输入的图标记“缺输入”，其余图继续执行。

### 2. 渲染完成

复用项目提供的 DataFactory 公开绘图接口与样式；接口不足时以标准 Matplotlib/mplhep 补充渲染。样式参数放在实际调用处，动态参数在使用处附近解释。

按当前分支读取绘图规范，混合图读取所有相关分支：

| 分支 | 必读章节 |
|---|---|
| 所有图 | §11 坐标轴与文字、§13 PDF 输出、§14 caption |
| Data/MC 等数据图 | §4 图形语义、§5 DELPHI 标头、§12 布局 |
| 一维直方图 | §6 Data/MC 示例、§7 marker/cap |
| 拟合图 | §4 的拟合规则、§9 residual 与副面板 |
| 派生量或 ratio | §8 误差展示；有副面板时另读 §9 |
| 二维分布或矩阵 | §10 colorbar、色标与数据几何 |
| 系统学图或可疑分布 | §15 异常的标记与上游核对事项 |
| 概念图 | §16；不套用数据图的标头、比例或误差要求 |

**完成条件：** 每张输入就绪的图已产生包含实际内容的 PDF 和对应 caption；生成失败的图标记“失败”，说明原因。审查已有图时只读取现有产物，修改范围遵循用户请求。

### 3. 检查完成

对渲染源码使用本 skill 的 `scripts/lint_scientific_plots.py`。混合脚本只检查渲染 cell：可将其源码原样摘录到临时 `.py` 文件做静态检查，无需执行该摘录。检查器按语法模式提示问题，不证明运行结果正确；动态调用、概念图或特殊图触发不适用规则时，记录适用性判断与视觉证据。

几何主要通过实际查看 PDF 确认。可选的 `scripts/check_plot_geometry.py --replay <脚本>` 仅用于确认不含上游计算的独立数据绘图脚本；它会重新执行并保存产物。bbox 重叠提示需视觉确认。概念图、不同实验标头或复杂多主面板采用视觉检查，记录检查器不适用的原因。

按 [视觉抽查](references/visual-review.md) 选图、逐图记录并修复问题；修改公共样式时复查受影响的图。

**完成条件：** 所有请求图都有产物状态和检查状态；已检查图的阻塞问题已修复，未验证或不适用项及影响已明确说明。抽查 PASS 仅覆盖实际查看的图。

## 交付

生成或修改图时交付源码/cell、输入说明与项目提供的运行方式、PDF、caption 和检查结果；审查任务交付检查结果及请求范围内的修改。逐图列明：产物状态（已生成/缺输入/失败；审查时为已有产物）和视觉状态（PASS/FAIL/未抽查/未验证），附抽样覆盖数与问题。任何缺图或未解决的阻塞问题都要明确标记为未完成，不能用总体 PASS 掩盖。

检查脚本使用本 skill 目录的绝对路径，运行环境沿用项目提供的环境。
