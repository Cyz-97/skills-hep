# 高能物理科研绘图

## 任务边界

消费上游最终结果和项目提供的实验元数据、归一化、误差定义、绘图工具及运行方式。绘图输入只读；物理计算、项目配置和缓存由各自流程负责。显示变换对中心值与误差一致应用，发现必要输入缺失时交回上游。

用户当前要求与适用的项目规范优先。用户要求保持已有布局或标注时沿用现状；审查与修改范围按用户请求执行。详细表达建议见 [绘图规范](references/plotting-standard.md)。

## 首次生成前

先在绘图 cell/代码段中准备以下正向清单，避免靠反复 lint 重写代码：

- 明确输入和样本身份：计数/密度、绝对/形状比较、权重及误差来源；仅使用已提供的信息。
- 表达最终结果：Data errorbar，MC stairs 加无外边框的 hatched 误差；单位、归一化和误差含义由轴标签与 caption 说明。
- 保持科学定义：中心值和误差使用同一变换；权重只应用一次；ratio 的分子误差与独立分母误差带分清来源。零分母或无效 bin 显示为缺失，不将占位值当成测量。已有图不能修改时，在交付说明中标记限制。
- 准备布局：主图大致接近 4:3 即可；优先上下主图与 ratio/residual 等宽、共享 x 轴、标签可读。使用 figure/GridSpec/边距组织面板，不强制用 `set_aspect` 或 `set_box_aspect` 锁定主副面板；二维等比例物理坐标按需使用数据 aspect。
- 拟合图展示上游参数及误差、$\chi^2/\mathrm{ndf}$ 和定义清楚的 residual；准备好标头、图例和必要的留白。
- 保存 PDF，并在 Subject 中写明 caption 与来源；交互式环境显示图像，无头运行关闭 figure。

Notebook 默认在结果生成后的独立 cell 从内存绘制；缓存重绘和批处理消费已有最终缓存。两种方式均可复用 DataFactory 公开封装；同一文件的上游 cell 不属于绘图违规。样式参数写在使用处，动态参数就地解释。

按图类型读取相关细则，混合图读取所有适用分支：

| 分支 | 绘图规范章节 |
|---|---|
| 所有图 | §11 文字与范围、§13 PDF、§14 caption |
| Data/MC | §4 语义、§5 标头、§6 示例、§7 marker/cap、§12 布局 |
| 拟合图 | §4 拟合表达、§9 residual |
| 派生量或 ratio | §8 误差与无效 bin、§9 副面板 |
| 二维分布或矩阵 | §5 图外标头、§10 色标与数据几何 |
| 系统学或异常形态 | §15 标记与上游核对事项 |
| 概念图 | §16；采用适用的文字与输出规则 |

**准备完成：** 每张请求图的输入与科学含义已明确，渲染和保存代码已准备；缺项单独记录，其余图继续。

## 首次实际渲染与结束条件

默认一轮实际渲染后查看 PDF，按 [视觉检查](references/visual-review.md) 确认科学表达、可读性和关键遮挡。可复用当前已查看的产物及记录，无需重跑上游或重画用户要求保留的图。

**完成：** 结果表达正确、文字可读、无关键遮挡、PDF 与 caption 对应。大致比例、留白多少、字体或 API 写法的差异不构成持续迭代理由。只有具体科学错误（如空比值伪装成 1、错误归一化、误差重复）或具体可读性缺陷触发修复，再仅查看受影响图；不要为清空检查提示而追加轮次。

## 可选诊断

需要定位具体问题或用户明确要求时才运行 `scripts/lint_scientific_plots.py <源码>`。它仅静态提示可疑科学表达，不要求源码包含某个绘图调用、formatter 名称或固定 CAPTION 变量。wrapper 内的 errorbar、动态 Subject caption 和上游 RDF cell 都是正常实现。没有提示只表示静态模式未命中，不证明科学结果正确。

`scripts/check_plot_geometry.py --replay <独立绘图脚本>` 仅用于定位具体遮挡，会重放并保存产物；不用于分析脚本，也不作为交付门槛。bbox 提示需要视觉确认。普通作图无需运行这两个工具；不接入 CI，不用精确比例或强制锁定 axes 替代视觉判断。

## 交付

交付源码/cell、输入说明与项目提供的运行方式、PDF、caption，以及简短检查结论。每张请求图列明产物状态（已生成/已有/缺输入/失败）与查看状态（已查看/未抽查/未验证），必要时列出问题。未查看图不继承抽查结论；未解决的科学问题或无法完成的请求明确说明。可选检查没有运行不影响正常交付，只在确有验证缺口时说明影响。
