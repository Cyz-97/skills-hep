# 首次渲染后的视觉检查

## 默认一轮

首次实际渲染后查看 PDF；已有被查看的图可沿用其产物与记录。四张以内全部查看，更多图默认选取四张有代表性的不同图：最复杂的主副面板、二维/矩阵、派生量/系统学、其余结论重要或视觉复杂者。缺少某类时从未选图补足。记录覆盖范围，未查看图不继承结论。

以 [绘图规范](plotting-standard.md) 的科学表达和可读性为依据：

- Data/MC 身份、权重、归一化、误差和 ratio 定义是否与输入一致；无效 bin 是否被标记或清楚说明。
- 拟合参数、residual、参考线、单位、标头和 caption 是否正确；wrapper 与动态 caption 都是正常实现。
- 在目标排版尺寸下是否可读，是否有关键遮挡或裁切；上下主副面板是否协调、等宽。
- 二维色标和数据几何是否表达真实结果；概念图的关系与箭头是否明确。

## 停止与修复

结果表达正确、可读、无关键遮挡即结束；大致比例、留白、字体或源码 API 差异不触发追加轮次。linter 和几何工具只在具体诊断需要时使用，不要求运行或清空提示。

仅对具体科学问题或可读性缺陷修复，再查看受影响图。公共样式有修改时补查一张其他受影响图。用户要求布局或标注保持现状时保留；已知科学限制写明影响，不能标成完全无问题。

## 简短结论

列明每张请求图的产物和查看状态，实际覆盖数，以及具体问题/已知限制即可。例如：“4/4 已查看，标注可读、布局保留；nJet 空分母 bin 的封装占位值不代表测量，统计诊断已排除，当前图按用户要求不重绘。”

未生成、未抽查或未验证项说明原因。检查结果只覆盖当前查看范围，不证明上游拟合或误差模型正确；不要求为普通作图新增报告框架。
