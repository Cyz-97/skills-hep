# 科研图视觉抽查

## 抽样与适用性

每次交付已生成或已有的 PDF，确定性选取四张，少于四张时全部查看。按以下顺序选取不同文件：最复杂的主副面板图、二维图或矩阵、派生量或系统学图、其余视觉最复杂或结论最重要的图；某类不存在时以未选图补足。纯概念图任务按文字与结构复杂度选择。记录文件名、入选理由和实际覆盖数。

抽样之外的图标记“未抽查”；查看工具不可用时标记“未验证”。抽查结论不外推到未查看的图，也不证明上游统计方法正确。

## 逐图检查

详细规则以 [绘图规范](plotting-standard.md) 为准，本文件只规定检查动作和证据：

| 检查对象 | 查看内容 | 规则入口 |
|---|---|---|
| 数据图 | 中心值与误差的表达、样本身份、曲线和图例是否一致 | §4、§6–8 |
| 拟合与副面板 | 参数面板、参考线、误差定义、模型有效范围 | §4、§9 |
| DELPHI 信息 | 身份和已知元数据，标头及图例是否遮挡 | §5 |
| 二维分布或矩阵 | 色标、colorbar、数据几何和单位 | §10 |
| 所有图 | 目标排版尺寸下的文字、范围、裁切、面板与 caption | §11–14 |
| 系统学或可疑形态 | 异常是否被标记，是否有上游说明或待核对事项 | §15 |
| 概念图 | 关系与箭头含义、文字可读性 | §16 |

发现与输入语义不符、误差缺失、身份错误、遮挡、不可读内容、白图或误导性范围时，记录 FAIL 和具体修复事项。修复后重新查看受影响图；公共样式修改时另补查一张使用该样式的图。

静态和几何检查的使用条件见正文“检查完成”。自动提示与视觉证据不一致时，记录适用规则及判断理由；不能把无法检查当作通过。

## 报告

用一个报告同时列明全部请求图的产物状态和视觉状态，不要求新增缓存或报告框架：

| 请求图 | 产物状态 | PDF/缺项/失败原因 | 视觉状态 | 入选理由或未检查原因 |
|---|---|---|---|---|
| figure_a | 已生成 | figure_a.pdf | PASS | 最复杂的主副面板图 |
| figure_b | 缺输入 | 未提供误差 | 未验证 | 未生成 |
| figure_c | 已生成 | figure_c.pdf | 未抽查 | 不在本次样本内 |

对每张实际查看的图写出物理表达、文字与布局、caption 的结论及具体问题；概念图使用其适用检查项。最后报告已查看数/已生成或已有数、未生成请求数、静态/几何检查结果及不适用项、未解决阻塞问题。状态枚举与交付完成标准见 [SKILL.md](../SKILL.md)。
